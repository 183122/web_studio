# ADR-0014: Template marketplace, live collaboration, code export, custom-code decision

- Status: Accepted (Phase 7)
- Context: M12 marketplace, real-time collaboration, M29 code export, "custom-code sandbox only after security review".
- Decision:
  1. **Marketplace = moderated data.** A submission snapshots the project's AppDefinition, sanitized: no records, workflows disabled, `email.send` actions with fixed recipients removed (would leak the author's or their customers' addresses), project id removed. Referenced images are copied out of the tenant prefix. A platform admin reviews a rendered preview and approves (new immutable `template_versions` row, version += 1) or rejects with a reason; authors are e-mailed. Listings show author organization, license (`free` = any use incl. commercial; `personal` = personal/non-profit), version and install count. Installing copies the files into the installer's workspace (storage quota checked) and rewrites asset refs. Authors or admins can delist; anyone signed in can report. No paid templates (needs payouts).
  2. **Collaboration over polling.** A 3-second heartbeat publishes page + selection (cache, 15 s TTL) and returns participants + head revision. A newer head is pulled automatically when the client has no local edits (`applyRemote` keeps page/selection); a save conflict is merged automatically by re-applying local typed commands on the new head and validating (`rebase`), with the manual conflict banner only when the merge is impossible. Avatars and coloured remote-selection outlines in the editor. No CRDT: concurrent edits to the *same* property resolve last-writer-wins at command granularity. No WebSocket server is required; a push transport (e.g. Reverb) can replace polling later without changing the model.
  3. **Export by capability.** ZIP with `site/` (HTML per page + the same runtime bundle in `static` mode: forms/tables show a notice; images at `/_assets/<id>.<ext>`; CSP meta), `data/` CSV (formula-safe) + JSON, `schema.sql` (MySQL 8: typed columns, NOT NULL, UNIQUE, CHECK for options, INSERTs, UTC datetimes), `app.json`, `openapi.json` for the hosted data API, README with a capability table and deployment recipe. Never exported: API keys, webhook secrets, OAuth tokens, payment data, password hashes. No generated server code: workflows/forms/auth are listed as "needs a server".
  4. **Custom code stays disabled** after the review in `docs/security/custom-code-sandbox-review.md`; a guard test fails the build if code-capable components or commands are added.
- Consequences: marketplace moderation is manual (queue in the admin console); collaboration latency ≈ 3 s and same-field edits are last-writer-wins; static export requires hosting at the domain root.
